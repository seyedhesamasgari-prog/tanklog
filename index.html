پشتیبان‌گیری و خروجی

پشتیبان JSON برای بازیابی کامل مناسب است. CSV را می‌توان در Excel باز کرد. برای PDF از گزینه چاپ/ذخیره PDF آیفون استفاده کنید.

پس از انتخاب مخزن، وارد صفحه گزارش همان مخزن می‌شوید؛ می‌توانید بازه تاریخ تعیین کنید و فقط سوابق دلخواه را تیک بزنید.

هشدار: بازیابی پشتیبان جایگزین اطلاعات فعلی می‌شود. قبل از بازیابی، خروجی پشتیبان فعلی را ذخیره کنید.
